# FUTURE_ML_01

## Future Interns - Machine Learning Internship

### Task 1 - Sales & Demand Forecasting for Businesses

## Objective

To forecast future sales using historical business transaction data.

## Dataset

UCI Online Retail Dataset.

The transaction data was cleaned and aggregated into daily sales data.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Model

Random Forest Regression

## Features

- Day
- Month
- Day of Week
- Year
- Lag 1
- Lag 7
- Lag 14
- 7-day Rolling Average

## Evaluation

The model was evaluated using:

- MAE
- RMSE
- MAPE

## Output

A 30-day future sales forecast was generated.

## Project Files

- `Sales_&_Demand_Forecasting.ipynb` - Complete project notebook
- `daily_sales.xlsx` - Processed daily sales dataset
- `30_day_sales_forecast.xlsx` - 30-day forecast results
